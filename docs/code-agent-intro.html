01 · Overview

一个 可自我进化的 编码代理

CodeAgent 不是一个"用完即弃"的脚本，而是一套可扩展的代理框架：它以 VS Code 的 contribution / service 分层为骨架，把「工具执行、上下文管理、技能系统、记忆系统、模型路由、基准测试」做成一个个可插拔模块 —— 既能当日常编码助手，也能作为团队内部 Agent 基础设施被反复打磨。

06 · Benchmark · agent_bm

用基准测试驱动演进

2026-08 起，基准测试从 code-agent 拆分为独立仓库 agent_bm： 每天凌晨 02:00（北京时间）自动对所有未测 commit 跑同一套任务，并把 code-agent 与其它 4 个 agent 放进同一张对比表， 趋势报告随站点发布 —— 让「每次改动是变快还是变慢」有数据可依。

🧪 测试集 suite（5 个任务）

  • 001 创建并验证文件（hello.txt）
  • 002 读取并搜索文件
  • 003 编辑文件
  • 004 列出目录结构
  • 005 执行终端命令

verify 阶段由脚本校验（fileExists / fileContains 等），非 LLM 自评，杜绝"自说自话"。

⚖️ 对比公平性设计

  • 同一模型：全部 agent 共用 deepseek-v4-pro（api.enflame.cn 内部端点）
  • 同一配置源：agents.json 单一来源，改模型只需改一行
  • 固定采样：temperature=0 · top-k=1 · memory=off，结果可复现
  • API key 不落库：运行时从 models.json 解析
  • 每日 02:00 定时：install_cron.sh 一键部署

wire 格式由各 agent 的 run 配置翻译：code-agent(codex 用 responses) / claude 用 messages / 其余用 chat/completions。

07 · Quick Start

60 秒上手

单文件分发，零运行时依赖 —— 装好即用。

1

安装（npm 全局）

# 或从 GitHub Releases 安装 .tgz
npm install -g code-agent
2

配置

cp $(npm root -g)/code-agent/config.template.yaml ~/.codeagent/config.yaml
# 编辑 ~/.codeagent/models.json 填入模型与 API key
3

运行

code-agent "write a hello world in Python"
code-agent --mode plan "design a REST API"
code-agent --parallel "t1" "t2"   # 并行任务
code-agent --resume                   # 恢复最近会话
4

构建与打包

npm run build:release   # esbuild minify → build/agent-cli.js (~121KB)
npm run pack             # 生成 code-agent-0.3.33.tgz
